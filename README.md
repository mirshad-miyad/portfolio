# Mohamed Mirshad - Full Stack Developer Portfolio

A modern, responsive, and high-performance personal portfolio website built with HTML5, CSS3, and Vanilla JavaScript.

## 🚀 Live Demo
- [Live Portfolio Website](https://mirshad-08.github.io/portfolio/) *(Update with your deployment link)*

---

## 📌 Features

- **Modern Aesthetic**: Dark-themed UI with cyan/purple gradient accents, glassmorphism navigation, subtle glows, and micro-interactions.
- **Hero Section**: 
  - Dynamic typewriter effect for developer role.
  - Interactive profile image showcase with rotating glowing rings and orbit particles.
  - Quick action buttons ("View Projects", "Download CV", and GitHub/LinkedIn links).
  - "Available for Opportunities" status indicator.
  - Smooth animated scroll indicator.
- **About Me**:
  - Highlights professional background and technical journey.
  - Key statistics cards with hover interactions.
  - Developer trait badges.
- **Interactive Skills Section**:
  - Categorized skill filters (All, Frontend, Backend, Database, Languages, Tools).
  - Interactive skill cards featuring branded tech icons (HTML5, CSS3, JavaScript, PHP, Node.js, Express.js, MySQL, Java, SQL, Git, GitHub).
- **Featured Projects**:
  - **LovingTravels**: Sri Lankan travel guide web application with destination discovery & mapping.
  - **LuxuryStay**: Hotel accommodation booking and reservation system.
  - Tech tags and quick action buttons (Source Code & Live Demo).
- **Education Timeline**:
  - Vertical timeline with glowing nodes and gradient line.
  - Academic qualifications including BSc (Hons) in IT at SLIIT and high school credentials.
- **Contact Section & Form**:
  - Direct communication channels (Email, LinkedIn, GitHub).
  - Client-side validated contact form with real-time feedback and animated success state.
- **Responsive Navigation**:
  - Sticky glassmorphic navbar with active section highlighting on scroll.
  - Smooth mobile hamburger menu and overlay.
  - "Back to top" floating action button.

---

## 🛠️ Built With

- **HTML5**: Semantic tags, accessibility (ARIA), and SEO meta tags.
- **CSS3**: Custom CSS variables, Flexbox, CSS Grid, keyframe animations, responsive media queries.
- **JavaScript (ES6+)**: IntersectionObserver for scroll animations, DOM manipulation, form validation, filter interactions.
- **Typography**: Inter & JetBrains Mono (Google Fonts).

## 💻 Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/MIRSHAD-08/portfolio.git
   ```

2. **Navigate to the directory:**
   ```bash
   cd portfolio
   ```

3. **Open `index.html` in your browser:**
   - Double-click `index.html`, or
   - Use VS Code Live Server extension.
